# About talk replies from Muse Gadgets

Talk machines only.
Only for models that have the media.file MP3 playback command.
Also make sure draw_file is there. (It is a standard command.)

Current setting: #1

Talk reply patterns
Applies to every pattern: make the talk reply text into audio (MP3).

---------------------------------------------------------------------

#1: Normal — Send the audio after the talk turn ends.
#2: Text image — Render the reply text as an image. Send the created text image and the audio without waiting for the talk turn to end. For long text, send several images with time gaps.
#3: Image — Create an image from the content of the reply text. Send the created image and the audio without waiting for the talk turn to end.

---------------------------------------------------------------------

The agreement ends here.
Below is a memo for the user.

Image generation can also include decorations in the image.
Like surrounding it with a cute frame, or, for weather, adding a fitting symbol for that place.
Add those to the image generation instruction and they will be reflected.
draw_file can send images regardless of audio.
